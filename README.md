# 🌟 IdiomMaster - 나만의 다빈도 영어 숙어 암기장

원어민들이 일상과 비즈니스에서 가장 자주 쓰는 **다빈도 필수 영어 숙어 45개**를 엄선하여 탑재하고, 생생한 실전 예문과 어원 유래 꿀팁, 그리고 플래시카드 & 퀴즈를 통해 완벽히 암기할 수 있는 **스마트 숙어 학습 프로그램**입니다.

---

## 🚀 주요 기능

### 1. 📇 3D 플래시카드 암기 모드
- **카드 뒤집기**: 마우스 클릭 또는 `Space` 키로 부드럽게 앞/뒷면을 전환합니다.
- **풍부한 학습 정보**:
  - 앞면: 숙어, 발음 기호, 🔊 **원어민 발음 듣기 (Web Speech TTS)**
  - 뒷면: 정확한 한국어 의미, 💡 **어원 유래 및 외우는 꿀팁**, 📖 **실전 예문 및 해석**, 💬 **2줄 실전 대화문**
- **스마트 상태 관리**:
  - `✅ 외웠어요! (↑)` vs `❌ 다시 볼래요 (↓)`
  - 즐겨찾기(★) 등록 및 🔀 랜덤 셔플 지원

### 2. 🎯 실전 퀴즈 챌린지
- **2가지 퀴즈 유형**:
  - 📚 **한글 뜻 맞추기 (객관식 4지선다)**: 숙어를 보고 알맞은 뜻 고르기
  - 🧩 **예문 속 빈칸 채우기 (클로즈 테스트)**: 문맥 예문 속 `[ ? ]`에 들어갈 알맞은 숙어 찾기
- **실시간 피드백 & 오답 노트**: 틀린 숙어는 자동으로 오답 노트에 정리되어 집중 복습 가능

### 3. 📚 숙어 사전 & 셀프 테스트 (가림판 모드)
- 실시간 키워드 검색 (영문, 한글, 태그 동시 검색)
- 필터 탭: [전체] [일상회화] [비즈니스] [감정·태도] [⭐ 즐겨찾기] [📖 복습필요] [✅ 암기완료]
- **👁️ 한글 뜻 가림판 모드**: 스스로 뜻을 떠올려본 뒤 마우스를 올리면(Hover) 뜻이 나타나는 자가 테스트 기능

### 4. ➕ 나만의 숙어 추가 / 수정 / 삭제
- 공부 중 새롭게 발견한 영어 숙어나 이디엄을 모달창에서 간편하게 등록
- 나만의 예문, 해석, 메모를 자유롭게 기록 가능
- 브라우저 로컬스토리지(LocalStorage)에 자동 영구 보존

### 5. 💾 데이터 백업 및 복원
- 언제든지 내 숙어장 데이터를 JSON 파일로 다운로드 백업 (`💾 버튼`)

## 🌐 GitHub 업로드 & Netlify 무료 실시간 배포 가이드

### 1단계: GitHub에 저장소 올리기
1. **GitHub 웹사이트(https://github.com/new)** 에서 `idiom-master`라는 이름의 새로운 빈 저장소(Public)를 생성합니다.
2. 터미널(PowerShell)에서 아래 두 명령어를 실행합니다:
   ```powershell
   git remote add origin https://github.com/NamSangok/idiom-master.git
   git push -u origin main
   ```
   *(또는 GitHub CLI를 이용하신다면 `gh auth login` 후 `gh repo create idiom-master --public --source=. --remote=origin --push` 명령어로 한 번에 생성 및 푸시 가능합니다.)*

### 2단계: Netlify 실시간 자동 배포 연동
1. **[Netlify](https://app.netlify.com)** 에 접속하여 로그인 (GitHub 계정으로 1초 로그인 추천)
2. **"Add new site"** → **"Import an existing project"** 클릭 후 **GitHub** 선택
3. 방금 올린 **`idiom-master`** 저장소 선택
4. 설정값 확인:
   - **Branch to deploy**: `main`
   - **Build command**: (비워둠)
   - **Publish directory**: `.`
5. **"Deploy idiom-master"** 버튼 클릭!
   - 약 10초 뒤 `https://[랜덤이름].netlify.app` 주소가 생성됩니다. (Site settings에서 원하는 도메인명으로 변경 가능)
   - 이제 GitHub에 코드를 푸시할 때마다 Netlify가 자동으로 실시간 배포를 수행합니다!

## 📱 스마트폰에서 "진짜 모바일 앱(PWA)"으로 설치하는 법

IdiomMaster는 PWA(Progressive Web App) 규격을 완벽 지원하므로, 앱스토어 설치 없이 홈 화면에 바로 설치할 수 있습니다:

1. **스마트폰 브라우저**에서 배포된 Netlify 주소로 접속합니다.
2. **iPhone (Safari)**:
   - 하단 중앙의 **[공유 버튼 📤]** 터치 → **[홈 화면에 추가 (+)]** 선택
3. **Android (Chrome)**:
   - 우측 상단 **[더보기 (⋮)]** 터치 → **[홈 화면에 추가]** 또는 **[앱 설치]** 선택
4. **결과**:
   - 스마트폰 홈 화면에 `숙어마스터` 앱 아이콘이 생성됩니다.
   - 브라우저 상단 주소창 없이 **네이티브 앱처럼 전체화면으로 실행**되며, 오프라인 및 음성 발음(TTS)도 완벽 지원됩니다!

## 📂 파일 구성
- `index.html` : 모던 UI 웹 애플리케이션 (플래시카드, 퀴즈, 사전, TTS 발음, 로컬 저장)
- `idiom_cli.py` : 파이썬 터미널용 대화형 암기 프로그램
- `idioms_data.json` : 엄선된 45개 다빈도 영어 숙어 데이터베이스
- `README.md` : 프로그램 사용 안내서
